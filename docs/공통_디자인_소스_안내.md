# 낙원레코드 공통 디자인 소스

최종 H안의 색상과 기본 글꼴을 기준으로 정리했습니다. 파일을 내려받아 각 화면에서 공통으로 사용할 수 있습니다.

## 파일 위치

- `frontend/src/styles/design-tokens.css`: 공통 색상과 폰트 이름
- `frontend/public/fonts/PretendardVariable.woff2`: 한글·영문 기본 글꼴 (전체 글꼴)
- `frontend/public/fonts/SpaceGrotesk-Variable.ttf`: 영문 제목에 선택적으로 사용할 글꼴. H안의 기본 글꼴은 Pretendard입니다.
- `frontend/public/fonts/*LICENSE*`, `*OFL*`: 각 글꼴의 사용 허가문
- `frontend/public/images/albums/placeholder.svg`: 음반 이미지가 없거나 불러오기 실패했을 때 사용할 임시 표지
- `frontend/public/images/brand/record-mark.svg`: 화면 작업을 위한 임시 레코드 심볼. 공식 로고 확정본이 아닙니다.

실제 음반 표지와 브랜드 로고는 아직 확정되지 않았습니다. 이 이미지는 화면을 만들 때 사용하는 임시 자료입니다. 실제 표지 파일은 사용 권한을 확인한 뒤 `frontend/public/images/albums/`에 추가합니다.

## 색상

| 용도 | 이름 | 색상 |
| --- | --- | --- |
| 화면 배경 | `--color-background` | `#0D0D0C` |
| 카드·패널 배경 | `--color-surface` | `#161615` |
| 마우스를 올린 영역 | `--color-surface-hover` | `#242422` |
| 기본 글자 | `--color-text` | `#FFFFFF` |
| 보조 글자 | `--color-text-muted` | `#A3A3A6` |
| 구분선 | `--color-border` | `#30302E` |
| 강조색 | `--color-accent` | `#FF6B2C` |

## 사용 예시

React 진입 파일이나 공통 스타일 파일에서 한 번 불러옵니다.

```js
import './styles/design-tokens.css'; // 실제 파일 위치에 맞게 경로를 조정하세요.
```

```css
body {
  background: var(--color-background);
  color: var(--color-text);
  font-family: var(--font-body);
}

.english-heading { font-family: var(--font-display-en); }
```

```jsx
<img src="/images/albums/placeholder.svg" alt="음반 표지 준비 중" />
```

실제 프로젝트 시작 파일이 `src/main.jsx`라면 위 import 경로를 그대로 쓸 수 있습니다. Tailwind를 사용하더라도 CSS 변수는 `bg-[var(--color-background)]`처럼 사용할 수 있습니다. 이미지의 `alt`에는 상황에 맞는 설명을 넣어 주세요.

서버의 `image_url`에는 `/images/albums/파일명`처럼 저장합니다. 프론트엔드의 public 폴더를 제공하는 개발·배포 설정이 필요합니다.
