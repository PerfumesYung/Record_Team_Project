# 낙원레코드 공통 디자인 소스

확정된 디자인의 H안 색상과 Space Grotesk + Pretendard 글꼴 조합을 기준으로 정리했습니다. 파일을 내려받아 각 화면에서 공통으로 사용할 수 있습니다.

## 파일 위치

- `frontend/src/styles/design-tokens.css`: 공통 색상과 폰트 이름
- `frontend/public/fonts/PretendardVariable.woff2`: 한글·영문 기본 글꼴 (전체 글꼴)
- `frontend/public/fonts/SpaceGrotesk-Variable.ttf`: 영문 제목·브랜드명에 사용하는 확정 글꼴. 한글은 Pretendard로 표시합니다.
- `frontend/public/fonts/*LICENSE*`, `*OFL*`: 각 글꼴의 사용 허가문
- `frontend/public/images/albums/placeholder.svg`: 음반 이미지가 없거나 불러오기 실패했을 때 사용할 임시 표지
- `frontend/public/images/brand/record-mark.svg`: 화면 작업을 위한 임시 레코드 심볼. 공식 로고 확정본이 아닙니다.

실제 음반 표지와 브랜드 로고는 아직 확정되지 않았습니다. 이 이미지는 화면을 만들 때 사용하는 임시 자료입니다. 실제 표지 파일은 사용 권한을 확인한 뒤 `frontend/public/images/albums/`에 추가합니다.

## 색상

| 용도 | 이름 | 색상 |
| --- | --- | --- |
| 화면 배경 | `--color-background` | `#0D0D0C` |
| 카드·패널 배경 | `--color-surface` | `#161615` |
| 마우스를 올린 영역 | `--color-surface-hover` | `#242422` |
| 기본 글자 | `--color-text` | `#FFFFFF` |
| 보조 글자 | `--color-text-muted` | `#A3A3A6` |
| 구분선 | `--color-border` | `#30302E` |
| 강조색 | `--color-accent` | `#FF6B2C` |

## 확정 글꼴

- 본문과 한글: **Pretendard Variable**
- 영문 제목과 브랜드명: **Space Grotesk**
- 한글·영문이 섞인 제목: `--font-heading`을 사용하면 영문은 Space Grotesk, 한글은 Pretendard로 표시합니다.

## 사용 예시

React 진입 파일이나 공통 스타일 파일에서 한 번 불러옵니다.

```js
import './styles/design-tokens.css'; // 실제 파일 위치에 맞게 경로를 조정하세요.
```

```css
body {
  background: var(--color-background);
  color: var(--color-text);
  font-family: var(--font-body);
}

.heading { font-family: var(--font-heading); } /* 영문 Space Grotesk / 한글 Pretendard */
```

```jsx
<h1 className="font-heading">NAKWON RECORDS 낙원레코드</h1>
<img src="/images/albums/placeholder.svg" alt="음반 표지 준비 중" />
```

실제 프로젝트 시작 파일이 `src/main.jsx`라면 위 import 경로를 그대로 쓸 수 있습니다. Tailwind CSS가 설정되어 있어 CSS 변수는 `bg-[var(--color-background)]`처럼 사용할 수 있습니다. 이미지의 `alt`에는 상황에 맞는 설명을 넣어 주세요.

서버의 `image_url`에는 `/images/albums/파일명`처럼 저장합니다. 프론트엔드의 public 폴더를 제공하는 개발·배포 설정이 필요합니다.

## Tailwind와 일반 CSS 함께 사용

Tailwind CSS 4가 Vite에 연결되어 있습니다. 배치·간격은 `flex`, `gap-4` 같은 클래스로 지정하고 공통 색상은 `bg-[var(--color-accent)]`처럼 재사용할 수 있습니다. 공통 CSS는 계속 사용할 수 있습니다. 같은 요소의 같은 속성을 두 곳에 지정하면 CSS 우선순위와 레이어에 따라 결과가 달라지므로 한 곳에서 관리하는 것이 좋습니다. 일반적인 레이어 밖 CSS는 Tailwind 유틸리티 레이어보다 우선할 수 있습니다. Tailwind의 기본 스타일 초기화(Preflight)도 적용됩니다.

```jsx
<button className="bg-[var(--color-accent)] px-5 py-3 text-white">
  장바구니 담기
</button>
```

기존 프로젝트를 받은 팀원은 최신 main을 받고 `frontend` 폴더에서 `npm ci`로 패키지를 다시 설치합니다.
